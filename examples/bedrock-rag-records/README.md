# RAG 평가 입력을 보존하는 오프라인 예제

```sh
cd examples/bedrock-rag-records
python3 -m unittest -v
```

표준 라이브러리만 사용하며 AWS 및 모델 API를 호출하지 않습니다.
실제 검색기와 생성기를 주입할 때는 별도 비용과 권한이 필요합니다.

- 질문마다 한 번만 검색하고 생성에 전달한 문맥을 그대로 저장합니다.
- 중간 실패 행을 유지해 질문·정답·답변이 어긋나지 않게 합니다.
- `legacy_ragas_rows`는 원본 노트북의 열 이름으로 변환하는 함수입니다.
  최신 Ragas 전체 실행 예제나 설치 환경을 제공하는 것은 아닙니다.
- 전송 직전 문맥을 추가로 자르거나 변환하면 실제 전송본도 별도로 기록해야 합니다.
- 해시는 문맥의 동일성을 확인하는 보조값이며 익명화 수단이 아닙니다.
- 테스트의 모든 문자열은 가상 데이터입니다. 원본 노트북과 클라우드 식별자는 포함하지 않습니다.
